# GenZen

A personal workspace for making, comparing, and organizing AI images and video.

## Run it

```
pnpm install
pnpm local:up
```

Required: Vercel (hosting, database, images), FAL (generation).
Optional: Anthropic, for the AI features.

Whatever is missing, `local:up` stops and says so, or makes it. Run it again.
