The reference image is the frame a scene of a film opens on. Produce the frame
the same scene ends on.

**The same place, the same people, the same look.** The identity, the clothing,
the surfaces, the light and the grade carry over exactly -- this is the same
camera in the same room minutes later, not another film. What has changed is
what the description below says has changed: the action, where people are, and
how the shot is framed.

Photographic if the reference is photographic, and never an illustration, a
diagram or a stylised render unless the reference itself is one.

No text, no labels, no borders, no captions and no subtitles.
